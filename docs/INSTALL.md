# 使用教程：把词典安装到欧路词典

[返回首页](../README.md) · [自行打包词典](BUILD.md)

本教程面向只想查词的用户，无需 Python、Git 或构建工具。请先安装欧路词典；菜单名称可能随平台和版本变化。

## 1. 下载词典文件

- [简洁版下载页面](../CS_AI_Dictionary_Simple_v1.1_EudicBuilder.eudic)：适合快速查词。
- [增强版下载页面](../CS_AI_Dictionary_Extended_v1.1_EudicBuilder.eudic)：包含可展开的语境、搭配、例句和辨析。

点击链接后，在 GitHub 文件页面点击下载按钮（Download raw file）。如果显示无法预览二进制文件，这是正常现象，请下载原文件，不要保存网页。

下载后确认文件后缀是 `.eudic`，不是 `.html` 或 `.txt`。两版可按需任选其一。现有成品对应 v1.1 的 3000 词；仓库后来增加的词条需要重新打包才会进入成品。

## 2. 在电脑上安装

1. 将 `.eudic` 存放在一个固定文件夹，例如“文档/我的词典”，不要只留在临时下载目录。
2. 打开欧路词典，找到“词库管理”或“词典库管理”。位置可能在设置或工具菜单中。
3. 使用本地添加/导入词库入口，选择下载的 `.eudic`；如果该版本要求指定扩充词库目录，则选择刚才存放文件的文件夹。
4. 回到词库列表，确认出现 CS-AI 词典，并启用它。若支持排序，可将其移到常用词典前面。
5. 按下面第 4 节查一个词，确认安装结果。

桌面端各版本入口不同；如果找不到本地添加选项，请从客户端帮助进入当前版本的扩充词库指南。项目已有 Windows 界面示例，尚未逐一验证所有客户端版本。

## 3. 在手机或平板上安装

可以使用欧路官方说明中的 WiFi 传输方式，将电脑上下载的文件传到移动端：

1. 让电脑与手机连接同一个 WiFi。
2. 在手机欧路词典中打开“帐号”，找到“WiFi 文件传输”或“WiFi 文件共享”，保持该页面打开。
3. 将手机显示的网址完整输入电脑浏览器地址栏。使用手机实际显示的地址，不要搜索这个地址。
4. 在传输网页中上传下载好的 `.eudic`，等待完成。
5. 回到手机的“词典库管理”，查找并启用新词典，然后查词验证。

以上传输入口参考 [欧路官方：添加扩充词库](https://docs.eudic.net/1/shi-yong-zhi-yin/tian-jia-kuo-chong-ci-ku)。移动端是否显示对应入口及附件兼容性以实际版本为准，本项目尚未完成所有移动端的实机验收。不要把词库导入“生词本”；生词本导入与扩充词库安装是不同功能。

## 4. 确认你查到的是本词典

在搜索框输入 `LoRA` 或 `neural network`。在结果中找到 CS-AI 对应的词典标题：简洁版显示紧凑释义，增强版显示语境、搭配、例句和辨析板块。点击增强版板块标题可尝试展开内容。

同一词可能同时显示欧路内置词典的结果，需查看本词典的标题或向下滚动。两版都安装时，同一个词出现两套释义属于正常现象。

## 常见问题

| 情况 | 处理方式 |
|---|---|
| 文件下载后变成网页 | 回到 GitHub 文件页，使用原文件下载按钮 |
| 词库列表里没有它 | 确认传输完成、文件后缀正确，并重新打开词库管理 |
| 能看到词库但没有释义 | 检查是否启用，先查上面的已收录示例词 |
| 新增的词查不到 | 数据提交不会更新旧 `.eudic`；需使用重新打包的文件 |
| 增强版排版或折叠异常 | 尝试更新客户端或使用简洁版，并反馈平台、版本、词头和截图 |
| 更新后显示多个旧版本 | 先确认新版正常，再在词库管理中停用旧版本 |

更新词典时，先保留旧文件，导入新版并检查后再替换。不要直接修改 `.eudic` 内容。
